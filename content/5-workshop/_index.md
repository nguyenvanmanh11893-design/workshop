# Workshop Guide: Building and Operating Cloud File Manager

---

### Workshop Introduction

This workshop provides a step-by-step hands-on guide from fundamentals to advanced concepts for building, testing, and operating a complete cloud storage application. Through the **Cloud File Manager** project, participants will directly experience and master key techniques in modern software engineering and AWS cloud service integration.

#### Workshop Modules:

1. **[5.1. Workshop Overview](5.1-overview/)**:
   * Context, learning goals, expected outcomes, and relationship to the 6-week internship roadmap.
2. **[5.2. Architecture and Technology](5.2-architecture-and-technology/)**:
   * End-to-end architecture breakdown, component responsibilities, data flows, security boundaries, and implementation status.
3. **[5.3. Prerequisites and Environment Setup](5.3-prerequisites/)**:
   * Toolchains, runtime requirements, secure environment variable configuration, and database migration execution.
4. **[5.4. Hands-on Exercises](5.4-hands-on/)**:
   * Direct-to-S3 uploads, serverless file validation, durable background workers, file lifecycles, and data reconciliation.
5. **[5.5. Technical Highlights](5.5-technical-highlights/)**:
   * In-depth analysis of key engineering mechanisms: Opaque Sessions, Quota Reservations, Lease Fencing, Version-aware Deletion, and IaC Terraform.
6. **[5.6. Testing and Evaluation](5.6-testing-and-evaluation/)**:
   * Summary of test execution (backend unit/integration tests, frontend tests, Terraform checks), acceptance criteria, and troubleshooting.
7. **[5.7. Resource Cleanup and Conclusion](5.7-cleanup/)**:
   * Safe teardown procedures for local environments and AWS cloud resources, along with key takeaways.
