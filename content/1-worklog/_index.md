This section presents the 6-week internship journey. Throughout the internship, I followed a systematic learning and practical roadmap, starting from fundamental AWS services, and progressively designing, developing, deploying, and operating a complete cloud-native application.

During the initial weeks, I focused on exploring and practicing core AWS services including IAM, EC2, VPC, Amazon S3, Amazon RDS, DynamoDB, Security Groups, Network ACLs, Route Tables, Internet Gateways, AWS Lambda, and Amazon CloudWatch. This formed an essential foundation for the capstone internship project.

Building on these foundational skills, I prepared for the internship project by conducting technology research, designing system architecture, developing the application, and configuring its deployment onto AWS Cloud.

The internship project, **Cloud File Manager**, was successfully architected and built utilizing Amazon S3, AWS Lambda, Amazon SQS, Amazon RDS (MySQL), Amazon CloudWatch, Infrastructure as Code with Terraform, and GitHub Actions CI/CD automation.
